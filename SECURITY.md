# Security Policy

## Supported versions

Only the latest release of `pyaging` published on PyPI receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/lucascamillomd/pyaging/security/advisories/new). Do not open a public issue for security reports. You will receive a response as soon as possible, and a fix will be released in the next version once the report is confirmed.
