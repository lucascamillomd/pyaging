# Original PAC reference predictions

`expected_predictions.csv` was generated by executing the unchanged original
Kuo et al. `pac_proteomic_age.R` using R 4.5.3. The source repository is
<https://github.com/kuo-lab-uchc/PAC>, pinned at
`e15edb66800f876a928cec9c8856500048c46fea`.

`input_npx.csv` contains eight synthetic sample profiles, with age in years and
128 protein NPX columns. Values were generated from sine and cosine functions;
they are not participant data. `pac_author_parameters.json` records fitted
numerical facts extracted from that source. No original R implementation is
vendored. The public original repository has no code license file; its paper
is CC BY 4.0. Original source hashes and attribution are retained in
`reference_provenance.json`.

To regenerate the reference after downloading the pinned original R source:

```sh
Rscript tests/data/proteoclock/generate_reference.R SOURCE_DIR tests/data/proteoclock
```

Cases cover complete measurements, supplied NA values and reversed feature
ordering. The generator also checks that the original function returns no
prediction for a missing protein column. API tests check sample ordering,
batching, mandatory age/protein columns, NaN propagation, and deliberately
imputed caller input. The paper used kNN with k=10 before model fitting; PAC
itself does not perform imputation or distribution matching.

The later Insilico wrapper rounds the original Gompertz constants and offers
cohort-dependent scaling. This conversion preserves the original full-precision
Kuo model. The restriction on ipfP3GPT weights is recorded in the provenance
file; this fixture does not contain those weights or a substitute model.
