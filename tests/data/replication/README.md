# Replication-clock reference fixtures

Expected predictions were generated by executing the original authors' R functions with R 4.5.3 on 2026-10-02. They are not computed by the pyaging implementation.

## CellDRIFT

Source: <https://github.com/MorganLevineLab/CellDRIFT>, commit `066b3e816795f3c0b372ff8d33f59185a490bd8b`. `clocks/build_replication.py` pins SHA256 checksums of all original R/data inputs. The 62-PC glmnet predictor is folded algebraically into a 2,322-CpG linear score; `celldrift_parameters.npz` records that transformation for offline runtime tests. `celldrift_input.npz` contains nine rows from the authors' `exampleDNAm.rda` (zero-based indices 0, 1, 2, 7, 31, 63, 89, 119, 152), one copy with every 37th CpG set to NaN, all-zero/all-one/all-half beta rows, and a linearly spaced beta row.

`generate_references.R` sources the unchanged author `R/CellDRIFT.R`, loads the original `.rda` files and invokes `CellDRIFT` directly with glmnet 5.1. The `full` expected column uses every feature; `partial` drops every 13th feature beginning at index 0. The authors distinguish supplied NaNs (zero) from absent columns (module means). Maximum observed absolute errors for the built artifact were 2.99e-13 and 9.95e-14 population doublings, respectively.

Upstream GitHub DESCRIPTION has an empty license field; the authors' [Zenodo record](https://doi.org/10.5281/zenodo.7693699) identifies the license only as Other (Open).

## MiAge

The original [Columbia software archive](https://www.columbia.edu/~sw2206/softwares/mitotic_age_R_code.zip) returned HTTP403. Original author `function_library.r`, `site_specific_parameters.Rdata`, `Additional_File1.csv`, and `README.txt` are preserved in [this pinned archive mirror](https://github.com/anilpsori/DNAm_pipelines_and_biomarkers/tree/d84d6adfc039355d5f9c962fc5faa7d1054f56b2/biomarkers/MiAge). We did not use its modified `MiAge.R` wrapper. File SHA256s are pinned in the builder. The pristine original ZIP could not be fetched, so its byte identity is not asserted.

All 268 CpG IDs and five shared annotation columns match the [original publisher supplement](https://doi.org/10.6084/m9.figshare.5620603.v2) in the same order. Publisher archive `kepi_a_1389361_sm3919.rar` has SHA256 `998a8b96cbe8261b9c2eb687020d7ac04f1df786d9f7bd2b98c0dbc1e524dbfb` and publisher-verified MD5 `c79c8d263f4451703eb17bdee785f2ca`. The supplementary table adds annotations but contains no fitted weights. The publisher supplement's CC BY4.0 license is not asserted for the separately archived author software/weights, which declare no license.

`miage_parameters.csv` stores the first three vectors, b/c/d, from the authors' `methyl.age` object without modification. Inputs comprise expected methylation `c+b**(n-1)*d` at n=1,10,100,500,1000,2000,4000,7000,9990,10000,12000; constant-zero/one/half and all-NaN rows; six random rows from NumPy `default_rng(1240).uniform(0,1,268)`; and the first random row with every 17th CpG missing. `generate_miage_references.R` calls the unchanged author `mitotic.age` function. `partial` omits every 13th CpG starting at index 0. Maximum observed error versus native R was 6.10e-5 relative cell divisions (full) and 2.08e-5 (partial), within the test tolerance of 1e-3. The CPU solver intentionally preserves the original five-start L-BFGS-B method, analytic gradient, bounds and stopping settings.

The original all-NaN result is the first tied optimizer start, 2008. This is explicitly tested to preserve source behavior, but is not biologically meaningful. A sample needs measured clock CpGs for interpretation.

## Regeneration

Build from the pinned source directories using the builder (build-only `rdata` dependency). Convert either committed input NPZ to CSV with columns=`features`, index=`samples` and data=`values`, using `float_format="%.17g"`. Then run:

```sh
Rscript tests/data/replication/generate_references.R /tmp/CellDRIFT-original /tmp/celldrift_fixture_input.csv tests/data/replication/celldrift_expected.csv
Rscript tests/data/replication/generate_miage_references.R /tmp/MiAge-original-mirror /tmp/miage_fixture_input.csv tests/data/replication/miage_expected.csv
uv run pytest tests/models/test_replication.py
```

The runtime tests require no network, R installation, or build-only dependency.
