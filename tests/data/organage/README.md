# OrganAge original-author oracle

Implementation source: [ludgergoeminne/organAging](https://github.com/ludgergoeminne/organAging),
commit `5147b0301ec7f4abdb10ef650d04f47454ddc8fd`.
Publication: Goeminne et al., *Cell Metabolism* 37, 205–222.e6 (2025),
[DOI 10.1016/j.cmet.2024.10.005](https://doi.org/10.1016/j.cmet.2024.10.005).

`source_manifest.json` records SHA-256 hashes of all 90 original coefficient
CSVs, the authors' example scoring script, README and license. The conversion
uses fold one, as recommended by the authors. All input columns, including
zero-coefficient columns, are retained. The four panels contain 23 full-model
outputs or 22 feature-reduced outputs each; the reduced panels have no Thyroid
model. The Female, Male, Organismal and Multi-organ outputs are additional
models released by the authors but excluded from their main manuscript discussion
(`scripts/R/Export_Supp_Tables.R`, lines 2–3).

`author_fold_one.json.gz` stores the original first-fold coefficient rows (including exact protein names and intercepts), extracted directly from the pinned author CSVs. It lets CI run all 90 models offline without generated `.pt` files. Local artifact parity is checked separately when built weights are available.

`input_npx.csv.gz` contains four synthetic samples over the 2,917-protein union:
zeros, signed values, smooth oscillating values, and positive values. There are
no individual-level human data. `expected_predictions.csv` contains 1,080
predictions generated by native R 4.5.3 (2026-03-11) for the 90 models across
three input scenarios:

- Complete input protein columns.
- Every third protein column omitted (one-based position in the stored matrix).
- An explicit NA in the first sample's first coefficient protein for each model.

`generate_reference.R` reads the scoring expressions **verbatim** from the
pinned original `scripts/R/Example_Script.R` and evaluates them in native R.
It does not compute expectations through the Python implementation. Both the
coefficient selection expression and the original `rowSums(sweep(...))`
expression are evaluated. The optional cohort-rescaling section and age-residual
calculation are deliberately not run: the converted models accept Olink NPX
and return direct predictions, in years for chronological models and relative
natural-log mortality hazards for mortality models.

The original example omits absent protein columns but does not pass
`na.rm=TRUE` to `rowSums`; explicit NA therefore propagates. The authors'
manuscript and README describe excluding missing protein measurements more
generally. These fixtures pin the released example's exact scoring behavior;
any preprocessing imputation by `df_to_adata` is a separate caller choice.

To regenerate, prepare a temporary original-author checkout at the pinned
commit and run:

```sh
gzip -dc tests/data/organage/input_npx.csv.gz > /tmp/organage-sources/input_npx.csv
Rscript tests/data/organage/generate_reference.R /tmp/organage-sources /tmp/organage_expected.csv
```

Use `uv run python clocks/build_organage.py --source-dir /tmp/organage-sources`
to reproduce model artifacts. Without `--source-dir`, the builder downloads and
verifies the original CSVs and caches them under the system temporary directory.
Each notebook provides the corresponding single-model build, with literal
curated metadata and source evidence comments.

The original author's Academic / Non-Commercial License is retained in
`LICENSE.author`. Every serialized model carries the full license and source
provenance; the builder also emits `.LICENSE.txt` and `.provenance.json`
sidecars. The coefficient artifacts require that license and attribution.

A secondary check against Biolearn's four OrganAge coefficient tables found all
90 models' nonzero terms represented and a maximum absolute coefficient
difference of `4.999570202279813e-11`, consistent with its decimal rounding.
Biolearn code and weights were not implementation or oracle sources.

## Current catalogue (0.5.5)

The original 90-model fixtures remain intact as historical author evidence.
Tests select the 46 full-panel outputs and remove `olink3000` from their names
when comparing to current artifacts. Reduced-panel outputs are no longer
published in the current catalogue. The coefficients and expected predictions
for retained models are unchanged; metadata now explicitly records plasma,
NPX input semantics and external normalization choices.
