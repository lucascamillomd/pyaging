# pyaging v0.5.0 — Blood-Chemistry Clocks + Feature-Range Safeguard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add four clinical aging clocks (kdmage, homeostaticdysregulation, phenoagesaopaulo, linage2) and a package-wide out-of-range input safeguard backed by a central feature-range registry, then release pyaging 0.5.0 with all 177 clocks synced to HuggingFace at tag v0.5.0.

**Architecture:** A single JSON registry (`src/pyaging/data/feature_ranges.json`) is the ground truth for feature units and plausibility bounds. A new inference step in `predict/_pred_utils.py` looks up each clock feature (per-feature entry, else a modality rule keyed by `data_type`) and logs warnings for out-of-range values without ever blocking prediction. The three BioAge-derived clocks get their parameters extracted by an R script that trains on NHANES III/IV with SI-unit variants so the fitted parameters are natively in the package's unit convention; each clock becomes a new `pyagingModel` subclass with a closed-form torch forward pass. LinAge2 is implemented from the paper's supplementary tables and validated against the authors' two published example subjects.

**Tech Stack:** Python 3.11+, PyTorch, AnnData/NumPy/Pandas, uv, pytest, Jupyter notebooks, R 4.3.1 with the `BioAge` package (already installed), HuggingFace Hub.

**Spec:** `docs/superpowers/specs/2026-08-20-v0.5.0-clocks-and-ranges-design.md`

## Global Constraints

- Sex feature is named `female` package-wide, coded `1` = female, `0` = male. No `sex`, `gender`, `Female`, or `Male` feature names anywhere.
- Chronological age feature is named `age` (lowercase) package-wide. No `Age`.
- Blood-chemistry unit convention (SI, matching the existing `phenoage` clock) — this is the authoritative list; every clinical clock uses these units:
  - `albumin` → g/L
  - `creatinine` → µmol/L
  - `glucose` → mmol/L
  - `c_reactive_protein` → mg/dL, supplied RAW. Each clock applies its own transform in preprocess(): phenoage uses ln (Levine 2018), the BioAge-derived clocks use log1p, LinAge2 logs internally. See Task 5b.
  - `lymphocyte_percent` → %
  - `mean_cell_volume` → fL
  - `red_cell_distribution_width` → %
  - `alkaline_phosphatase` → U/L
  - `white_blood_cell_count` → 10³ cells/µL
  - `total_cholesterol` → mmol/L
  - `blood_urea_nitrogen` → mmol/L
  - `hemoglobin_a1c` → %
  - `systolic_blood_pressure` → mmHg
  - `forced_expiratory_volume` → L
  - `age` → years
  - `female` → indicator, 0 or 1
- One feature name maps to exactly one unit package-wide. Adding a feature name with a conflicting unit is a bug.
- Feature ranges are **broad plausibility bounds** (catch unit errors and swapped columns), never clinical reference ranges.
- The range check is **warn-only**. It must never raise, never mutate data, and never change a prediction.
- Modality rules by `data_type`: `DNA methylation` → [0, 1]; `transcriptomics`, `histone modification`, `chromatin accessibility` → [0, ∞); `clinical biomarkers` → per-feature registry lookup.
- No `input_scale` attribute and no counts-vs-log inference. Expected scale is communicated through feature units only.
- Loading must tolerate clocks saved before v0.5.0 (missing new attributes) via `getattr` fallbacks.
- Version target: `0.5.0` in `src/pyaging/__init__.py`; all HF clock repos re-synced and tagged `v0.5.0`.
- Follow existing repo conventions: `uv run` for all Python commands, ruff lint/format via pre-commit, tests under `tests/` mirroring `src/pyaging/` structure.

Create `src/pyaging/utils/_feature_ranges.py`:

```python
"""Package-wide ground truth for feature units and plausibility ranges."""

import json
import math
from functools import lru_cache
from importlib import resources

_UNBOUNDED = {"unit": None, "low": None, "high": None}


@lru_cache(maxsize=1)
def load_feature_range_registry() -> dict:
    """Load and cache the feature range registry shipped with the package."""
    source = resources.files("pyaging.data").joinpath("feature_ranges.json")
    return json.loads(source.read_text(encoding="utf-8"))


def _as_records(features, data_type, units):
    registry = load_feature_range_registry()
    per_feature = registry["features"]
    default = registry["modality_defaults"].get(data_type, _UNBOUNDED)

    for index, feature in enumerate(features):
        entry = per_feature.get(feature, default)
        unit = units[index] if units is not None else entry["unit"]
        yield {
            "feature": feature,
            "unit": unit,
            "low": -math.inf if entry["low"] is None else float(entry["low"]),
            "high": math.inf if entry["high"] is None else float(entry["high"]),
        }


def resolve_feature_ranges(features, data_type, feature_units=None) -> list[dict]:
    """Resolve each feature to its unit and plausibility bounds.

    A per-feature registry entry wins over the modality default for the clock's
    ``data_type``; features in neither are unbounded. ``feature_units``, when
    given, overrides the registry unit (a single string applies to all features).
    """
    features = list(features)
    if isinstance(feature_units, str):
        feature_units = [feature_units] * len(features)
    if feature_units is not None and len(feature_units) != len(features):
        raise ValueError(
            f"feature_units has {len(feature_units)} entries but there are {len(features)} features"
        )
    return list(_as_records(features, data_type, feature_units))


def get_feature_ranges(clock_name: str):
    """Return a clock's feature units and normal ranges as a DataFrame.

    Examples
    --------
    >>> get_feature_ranges("phenoage")  # doctest: +SKIP
    """
    import pandas as pd

    from ..predict import load_clock

    model = load_clock(clock_name, verbose=False)
    records = resolve_feature_ranges(
        model.features,
        model.metadata.get("data_type"),
        getattr(model, "feature_units", None),
    )
    return pd.DataFrame.from_records(records)
```

```python
_MAX_REPORTED_FEATURES = 5


@progress("Check feature ranges")
def check_feature_ranges(
    adata: anndata.AnnData,
    model: pyagingModel,
    logger,
    indent_level: int = 2,
) -> None:
    """Warn when input values fall outside a feature's plausible range.

    Ranges come from the package-wide registry (per-feature entry, else the
    modality default for the clock's ``data_type``). Out-of-range values usually
    mean wrong units or swapped columns, so this warns and never blocks: the
    data is not inspected for clinical abnormality and is never modified.
    """
    records = resolve_feature_ranges(
        model.features,
        model.metadata.get("data_type"),
        getattr(model, "feature_units", None),
    )
    matrix = np.asarray(adata.obsm[f"X_{model.metadata['clock_name']}"], dtype=float)

    offenders = []
    for index, record in enumerate(records):
        column = matrix[:, index]
        finite = ~np.isnan(column)
        outside = finite & ((column < record["low"]) | (column > record["high"]))
        count = int(outside.sum())
        if count:
            offenders.append((record, 100 * count / int(finite.sum())))

    if not offenders:
        logger.info("All feature values are within their expected ranges.", indent_level=indent_level + 1)
        return

    logger.warning(
        f"{len(offenders)} of {len(records)} features have values outside their expected range. "
        "This usually means the data is in different units than the clock expects.",
        indent_level=indent_level + 1,
    )
    for record, percent in offenders[:_MAX_REPORTED_FEATURES]:
        unit = f" {record['unit']}" if record["unit"] else ""
        logger.warning(
            f"{record['feature']}: {percent:.2f}% of values outside "
            f"[{record['low']:g}, {record['high']:g}]{unit}",
            indent_level=indent_level + 2,
        )
    if len(offenders) > _MAX_REPORTED_FEATURES:
        logger.warning(
            f"...and {len(offenders) - _MAX_REPORTED_FEATURES} more features",
            indent_level=indent_level + 2,
        )
```

```python
#!/usr/bin/env python3
"""One-off v0.5.0 migration for saved clock weights.

Renames legacy covariate features to their harmonized package-wide names.
Task 11 extends this script to also write feature units.
"""

import argparse
from pathlib import Path

import torch

LEGACY_FEATURE_NAMES = {"Female": "female", "Age": "age"}


def rename_features(features):
    """Return ``features`` with legacy covariate names replaced."""
    renamed = [LEGACY_FEATURE_NAMES.get(feature, feature) for feature in features]
    for old, new in LEGACY_FEATURE_NAMES.items():
        if old in features and new in features:
            raise ValueError(f"cannot rename {old!r}: {new!r} is already present")
    return renamed


def patch_weight_file(path: Path) -> bool:
    """Apply the v0.5.0 migration to one saved clock; return True if it changed."""
    model = torch.load(path, weights_only=False)
    renamed = rename_features(model.features)
    if renamed == list(model.features):
        return False
    model.features = renamed
    torch.save(model, path)
    return True


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("weights_dir", type=Path, help="directory of .pt clock weights")
    arguments = parser.parse_args()

    changed = [path.name for path in sorted(arguments.weights_dir.glob("*.pt")) if patch_weight_file(path)]
    print(f"patched {len(changed)} clocks: {', '.join(changed) if changed else 'none'}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```r
  ref_mean <- colMeans(ref_matrix, na.rm = TRUE)
  ref_sd <- apply(ref_matrix, 2, sd, na.rm = TRUE)
```

```r
hd_fit_for <- function(female_value) {
  reference <- hd_reference(female_value)
  ref_matrix <- as.matrix(reference[, hd_markers])
  ref_mean <- colMeans(ref_matrix, na.rm = TRUE)
  ref_sd <- apply(ref_matrix, 2, sd, na.rm = TRUE)

  standardize <- function(matrix_in) sweep(sweep(matrix_in, 2, ref_mean, "-"), 2, ref_sd, "/")
  ref_z <- na.omit(standardize(ref_matrix))
  center <- colMeans(ref_z)
  covariance <- var(ref_z)

  projection <- na.omit(standardize(as.matrix(
    (nhanes4 %>% filter(female == female_value))[, hd_markers]
  )))
  distances <- sqrt(mahalanobis(projection, center, covariance))

  list(
    biomarkers = hd_markers,
    reference_mean = as.numeric(ref_mean),
    reference_sd = as.numeric(ref_sd),
    standardized_center = as.numeric(center),
    standardized_covariance = unname(as.matrix(covariance)),
    log_hd_sd = sd(log(distances), na.rm = TRUE)
  )
}

write_json(
```

### Task 5b: Raw C-reactive protein everywhere

**Why this task exists.** Task 5 discovered that BioAge's `lncrp` column is `log1p(CRP in mg/dL)`, while pyaging's existing `phenoage` clock takes `log_crp` = `ln(CRP in mg/dL)` per Levine 2018. Same feature name, two different transforms — and the blood-chemistry tutorial runs both clocks against one dataframe, so one of them would be silently wrong. Verified empirically in R: BioAge's `crp = 0.210` maps to `lncrp = 0.191`, which is `log1p(0.210)`; `log(0.210)` is `-1.56`.

The fix, decided by the user: **users supply the raw measurement and each clock applies its own transform in `preprocess()`.** A pre-transformed input is a footgun — nothing in the name `log_crp` hints at either the `+1` or at mg/dL rather than the more common mg/L.

**Audit result (already performed, no need to repeat).** Across all 173 clocks, `log_crp` in `phenoage` is the ONLY pre-transformed user-supplied feature. Specifically:
- `lymphocyte_percent` is a genuine unit (%), not a transform.
- `grimage2logcrp` in `cpgptgrimage3` / `cpgptpcgrimage3` is a DNAm *surrogate* produced by another clock, not a lab measurement. Out of scope, but document it as a model output.
- `mammalian*` clocks carry species one-hot indicators; the `[0, 1]` methylation rule is coincidentally correct for them.
- `meer` / `petkovich` / `stubbs` / `thompson` use `chr:pos` RRBS ratios, also `[0, 1]`.
- LinAge2 already takes raw CRP and logs internally, so it needs no change.

**This is a user-facing breaking change** — the only one in v0.5.0 — and must be called out as such in the changelog and PR.

```python
class KDMAge(pyagingModel):
    """Klemera-Doubal biological age with sex-specific NHANES III parameters."""

    def __init__(self):
        super().__init__()

    def preprocess(self, x):
        return x

    def postprocess(self, x):
        biomarkers, age, female = x[:, :-2], x[:, -2], x[:, -1:]

        def estimate(q, k, s, s_ba2):
            weights = k / s**2
            numerator = ((biomarkers - q) * weights).sum(dim=1)
            denominator = ((k / s) ** 2).sum()
            return (numerator + age / s_ba2) / (denominator + 1 / s_ba2)

        female_age = estimate(self.q_female, self.k_female, self.s_female, self.s_ba2_female)
        male_age = estimate(self.q_male, self.k_male, self.s_male, self.s_ba2_male)
        return torch.where(female.squeeze(-1) == 1, female_age, male_age).unsqueeze(-1)
```

```python
class HomeostaticDysregulation(pyagingModel):
    """Mahalanobis distance from a young, healthy NHANES III reference cohort."""

    def __init__(self):
        super().__init__()

    def preprocess(self, x):
        return x

    def postprocess(self, x):
        biomarkers, female = x[:, :-1], x[:, -1]

        def distance(reference_mean, reference_sd, center, precision, log_hd_sd):
            deviation = (biomarkers - reference_mean) / reference_sd - center
            squared = (deviation @ precision * deviation).sum(dim=1)
            return torch.log(torch.sqrt(squared)) / log_hd_sd

        female_score = distance(
            self.reference_mean_female, self.reference_sd_female,
            self.center_female, self.precision_female, self.log_hd_sd_female,
        )
        male_score = distance(
            self.reference_mean_male, self.reference_sd_male,
            self.center_male, self.precision_male, self.log_hd_sd_male,
        )
        return torch.where(female == 1, female_score, male_score).unsqueeze(-1)
```

```python
def mortality_to_phenoage_saopaulo(x, m_n, m_d, ba_n, ba_d, ba_i):
    """Convert a Gompertz mortality score to phenotypic age using refit constants.

    Unlike ``mortality_to_phenoage``, whose constants come from Levine's 2018
    publication, the constants here are fit alongside the clock's coefficients.
    """
    mortality = 1 - torch.exp(m_n * torch.exp(x) / m_d)
    return torch.log(ba_n * torch.log(1 - mortality)) / ba_d + ba_i
```

The inference pipeline, per subject:

```
inputs: 57 numeric measurements + 26 questionnaire codes + sex + age_years
  -> digitize cotinine into 0/1/2/3
  -> derive fs1Score, fs2Score, fs3Score, LDLV, crAlbRat
  -> assemble the 59-feature vector in the fixed order
  -> natural log on the 13 flagged features (allow -inf; do NOT guard with NaN)
  -> z = (x - median_sex) / mad_sex, EXCEPT five columns that pass through unnormalized
        (fs1Score, fs2Score, fs3Score, LBXCOT, LBDBANO)
  -> clip(z, -6, 6)                       # -inf from log(0) folds to exactly -6
  -> pc = z @ V_sex                       # (59,) @ (59, 59)
  -> lp        = beta_sex . (concat([age_months], pc)[pc_index_sex] - means_sex)
     lp_null   = beta_null_sex * (age_months - mean_null_sex)
     MRDT_sex  = round(log(2) / beta_null_sex, 2)     # the rounding is load-bearing
     BA_months = age_months + (lp - lp_null) / log(2) * MRDT_sex
  -> BA_years  = BA_months / 12
```

Constant tensors per sex: `median[59]`, `mad[59]`, `skip_mask[59]`, `log_mask[59]`, `V[59, 59]`,
`pc_index[17]`, `beta[18]`, `means[18]`, `beta_null`, `mean_null`, `MRDT`.

```python
import math

import numpy as np
import pandas as pd
import pytest

import pyaging as pya

pytestmark = pytest.mark.full_catalog

# clock name -> [prediction at each feature's lower bound, prediction at its upper bound].
# Generated by scripts/generate_boundary_gold.py; regenerate deliberately, never to
# paper over a change in predictions.
boundary_gold_standard_dict: dict[str, list[float]] = {}

_FALLBACK_SPAN = 10.0


def boundary_inputs(model):
    """Return (lower, upper) input rows built from each feature's plausibility range."""
    records = pya.utils.resolve_feature_ranges(
        model.features, model.metadata.get("data_type"), getattr(model, "feature_units", None)
    )
    lower, upper = [], []
    for record in records:
        low = record["low"] if math.isfinite(record["low"]) else 0.0
        high = record["high"] if math.isfinite(record["high"]) else low + _FALLBACK_SPAN
        lower.append(low)
        upper.append(high)
    return lower, upper


@pytest.mark.parametrize("clock_name", sorted(boundary_gold_standard_dict))
def test_boundary_predictions_match_gold(clock_name):
    clock = pya.pred.load_clock(clock_name, verbose=False)
    lower, upper = boundary_inputs(clock)
    frame = pd.DataFrame([lower, upper], columns=clock.features)
    adata = pya.pp.df_to_adata(frame, imputer_strategy="constant", verbose=False)
    pya.pred.predict_age(adata, clock_name, verbose=False)

    np.testing.assert_allclose(
        adata.obs[clock_name].to_numpy(),
        boundary_gold_standard_dict[clock_name],
        rtol=0,
        atol=0.01,
    )
```
